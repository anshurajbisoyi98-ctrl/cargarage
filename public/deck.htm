SIH Jury Defense

MENTOR DEFENSE Q&A

Authoritative engineering answers for evaluation panel scrutiny

JURY DEFENSE

Q1: Why httpOnly cookies instead of localStorage?

Defense: localStorage is vulnerable to Cross-Site Scripting (XSS). Any third-party script can steal tokens. An httpOnly, SameSite: Strict cookie is completely inaccessible to JavaScript, guaranteeing XSS immunity while preventing CSRF.

Q2: How do you prevent cross-tenant vehicle tampering?

Defense: Our centralized ownedVehicle(vehicleId, user) middleware validates String(vehicle.owner) === String(user._id). Unauthorized requests throw an immediate 403 Forbidden at the database layer.

Q3: What happens if a network crash occurs during invoicing?

Defense: Invoicing runs inside a MongoDB ACID transaction. Odometer update, request completion, and invoice creation commit together. Any failure triggers an automatic rollback with zero orphaned records.

Q4: How does the timer ensure single-entry execution?

Defense: The loading sequence is executed during initial asset decoding. Upon 100% completion, .loading.done fades out the element. Because internal navigation runs as an SPA, the timer never re-executes until a browser refresh.
